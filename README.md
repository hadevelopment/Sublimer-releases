# Sublimer Releases

Canal publico de auto-update del cliente de escritorio Sublimer.
Este repo NO se clona: los instaladores (Sublimer-Setup-X.Y.Z.exe),
blockmaps y latest.yml se publican como assets de GitHub Releases.

Consumidor: electron-updater en vrs-desktop-client (provider github,
owner hadevelopment, repo Sublimer-releases).
